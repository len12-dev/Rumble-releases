# Rumble — versions de test

Dictée vocale pour Windows (Whisper, commandes vocales, nettoyage du texte par modèle local).

## Installation
1. Téléchargez `Rumble.exe` depuis la dernière [release](https://github.com/len12-dev/Rumble-releases/releases).
2. Lancez-le. Windows peut afficher un avertissement « éditeur inconnu » : c'est normal pour une version de test.
3. Ctrl + Alt + V pour démarrer ou arrêter la dictée.

Pour le nettoyage par modèle local (optionnel), installez [Ollama](https://ollama.com) puis lancez `ollama pull qwen2.5:3b`.

Le code source est dans un dépôt privé.
